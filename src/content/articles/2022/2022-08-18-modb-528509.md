# **开篇警示**

1. 生产环境密码不可使用本文中的 root 应使用安全等级更高的 大写字母 小写字母 特殊符号 数字16位组合。
2. 生产环境端口避免使用默认端口27017
3. 生产环境分片组应构建在不同的物理硬盘上，本文仅以文件夹代替。
4. 生产环境组网应更加合理，mongos 与 shard 分机器部署保障服务可用性。

# **构建ConfigServer**

#### **构建config-server1**

Docker挂载文件夹

```
df -h # 查看空间内最大分区
```

选择一个空间最大的文件夹构建mongo数据与配置文件夹

```
mkdir -p home/docker/mongo-cluster/config-server1/{data,conf}
```

配置文件

```
echo "
#  网络设置
net:
port: 27011  #端口号
replication:
replSetName: configsvr
sharding:
clusterRole: configsvr
security:
authorization: enabled #是否开启认证
  keyFile: /data/configdb/mongo_ssl.key #ssl.key路径 "  > home/docker/mongo-cluster/config-server1/conf/mongo.conf
```

# **Mongos + Nginx负载**

```
yum install nginx
vim /etc/nginx/nginx.conf
```

nginx conf内容

```
user nginx;
worker_processes auto;
error_log /var/log/nginx/error.log;
pid /run/nginx.pid;




# Load dynamic modules. See /usr/share/doc/nginx/README.dynamic.
include /usr/share/nginx/modules/*.conf;




events {
worker_connections 1024;
}
stream {
upstream stream_mongos {
server 192.0.2.12:27021;
server 192.0.2.13:27022;
server 192.0.2.14:27023;
        }
server {
listen 27017;
proxy_pass stream_mongos;
        }
}




http {
log_format  main  '$remote_addr - $remote_user [$time_local] "$request" '
'$status $body_bytes_sent "$http_referer" '
'"$http_user_power_idnt" "$http_x_forwarded_for"';




access_log  /var/log/nginx/access.log  main;




sendfile            on;
tcp_nopush          on;
tcp_nodelay         on;
keepalive_timeout   65;
types_hash_max_size 4096;




include             /etc/nginx/mime.types;
default_type        application/octet-stream;
server {
listen       80;
  }
}
```

#指定hero数据库中使用分片
