**反向代理**

需求是我想访问一个ip通过正则匹配来访问不同的服务器。

配置

```
server {
        listen       80;
        location /pro/ {
    proxy_pass   http://127.0.0.1:8080/;
  }
     location /dev/ {
    proxy_pass   http://192.0.2.13:8080/;
  }
  }
```

完整配置文件

```
user nginx;
worker_processes auto;
error_log /var/log/nginx/error.log;
pid /run/nginx.pid;




# Load dynamic modules. See /usr/share/doc/nginx/README.dynamic.
include /usr/share/nginx/modules/*.conf;




events {
    worker_connections 1024;
}




http {
    log_format  main  '$remote_addr - $remote_user [$time_local] "$request" '
                      '$status $body_bytes_sent "$http_referer" '
                      '"$http_user_agent" "$http_x_forwarded_for"';




    access_log  /var/log/nginx/access.log  main;




    sendfile            on;
    tcp_nopush          on;
    tcp_nodelay         on;
    keepalive_timeout   65;
    types_hash_max_size 4096;




    include             /etc/nginx/mime.types;
    default_type        application/octet-stream;








    server {
        listen       80;
        location /pro/ {
    proxy_pass   http://127.0.0.1:8080/;
  }
     location /dev/ {
    proxy_pass   http://192.0.2.13:8080/;
  }
  }
}
```

**负载均衡**

配置

```
upstream zuoyang {
        server 127.0.0.1:8080 weight=3;
        server 192.0.2.13:8080;
    }
    server {
        listen       80;
        location / {
    proxy_pass   http://zuoyang;
  }
  }
```

upstream 负载配置

zuoyang 监听地址，可以自定义

weight 权重，例如

```
配置
upstream zuoyang {
        server 127.0.0.1:8080 weight=4;
        server 192.0.2.13:8080 weight=1;
    }
```

就是每 5 个新请求,四个请求将定向到127.0.0.1，一个请求将定向到192.0.2.13,让我们用curl看下吧
