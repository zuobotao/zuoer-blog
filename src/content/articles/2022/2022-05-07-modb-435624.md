**数据类型**

上一节我们说到了几种数据数据形式,接下我们看看它们在Golang中的数据格式是啥吧。这里我们会引入一个新包，"reflect"包使用其中的TypeOf函数查看数据的类型，下面让我们看看吧。

```
package main


import (
"fmt"
"reflect"
)


func main() {
  fmt.Println(reflect.TypeOf("我是字符串"))
  fmt.Println(reflect.TypeOf(true))
  fmt.Println(reflect.TypeOf(12138))
  fmt.Println(reflect.TypeOf(12.138))
}
```

| --- | --- |
| 类型 | 描述 |
| string | 字符串 |
| bool | 布尔值 |
| int | 整数 |
| float64 | 小数 |

**变量**

变量一种可变的量，在Golang中使用var关键字加上变量名与数据类型数据类型即可。

```
func main() {
var name string;
// 关键字 变量名 数据类型 
}
```

声名完变量后，可以使用=等号为其赋值。

```
package main


import "fmt"


func main() {
var name string
  name = "zuoyang"
  fmt.Println(name)
}
```

只要你赋完值就可以在上下文中使用了

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220714_4f1ce002-0360-11ed-846f-fa163eb4f6be.png)

Golang可以一次定义同一种数据类型的多个变量，如下

```
package main


import "fmt"


func main() {
var name string
var age,height int
// 同一种数据类型的多个变量
  name = "zuoyang"
  age = 18
  height = 199
  fmt.Println(name)
  fmt.Println(age)
  fmt.Println(height)
}
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220714_4f367efe-0360-11ed-846f-fa163eb4f6be.png)

同样也可以同一语句中为多个变量赋值。如下

```
package main


import "fmt"


func main() {
var name string
var age,height int
// 同一种数据类型的多个变量
  name,age,height = "zuoyang",18,199
//同一语句中为多个变量赋值
  fmt.Println(name)
  fmt.Println(age)
  fmt.Println(height)
}
```

注意值的个数和数据类型要跟变量对应上，否则会报错

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220714_4f544ca4-0360-11ed-846f-fa163eb4f6be.png)

你也可以在定义变量的时候直接赋值，如下

```
package main


import "fmt"


func main() {
var name string = "zuoyang"
var age,height int = 18,199
  fmt.Println("姓名：",name,"，年龄：",age,",身高：",height)
}
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220714_4f678c06-0360-11ed-846f-fa163eb4f6be.png)

如果你在定义变量时为其赋值，通常可以在定义中省略变量类型，如下

```
package main


import "fmt"


func main() {
var name = "zuoyang"
var age,height = 18,199
  fmt.Println("姓名：",name,"，年龄：",age,",身高：",height)
}
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220714_4f86b888-0360-11ed-846f-fa163eb4f6be.png)

默认值，如果我们不对类型赋值那么它的默认值是啥呢？如下

```
package main


import "fmt"


func main() {
var name string
var age,height int
var isMan bool
  fmt.Println("姓名：",name,"，年龄：",age,",身高：",height,",性别：",isMan)
}
```

短声名变量，简便写法，如下

```
package main


import "fmt"


func main() {
  name := "zuoyang"
  age,height := 18,199
  isMan := false
  fmt.Println("姓名：",name,"，年龄：",age,",身高：",height,",性别：",isMan)
}
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220714_4fc1360c-0360-11ed-846f-fa163eb4f6be.png)

！简便写法注意事项

1. 一个func函数内一个变量名只能定义一次，否则会报错

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220714_50c3cb82-0360-11ed-846f-fa163eb4f6be.png)

1. 不能删除:，只剩等号的话对于Golang来说是赋值
2. 定义的变量必须被使用
3. 数据类型要匹配
4. 定义的变量名和赋值的数量要匹配
