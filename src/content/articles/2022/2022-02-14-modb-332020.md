**常用命令**

**查看本地镜像**

```
docker images
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220221_4d2fe054-92ff-11ec-9cfa-fa163eb4f6be.png)

**运行镜像**

```
docker run <IMAGE ID>
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220221_4d5ba716-92ff-11ec-9cfa-fa163eb4f6be.png)

这个镜像我部署了一个SpringBoot的HelloWorld项目，由于当前是使用非后台模式启动所以会在控制台输出运行信息。

**后台运行镜像**

```
docker run -d <IMAGE ID>
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220221_4da74e0a-92ff-11ec-9cfa-fa163eb4f6be.png)

**启动时绑定镜像端口与本机端口映射**

```
docker run -d -p 本机端口:镜像端口 <IMAGE ID>
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220221_4deb67b6-92ff-11ec-9cfa-fa163eb4f6be.png)

**查看运行中镜像**

```
docker ps
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220221_4e2158b2-92ff-11ec-9cfa-fa163eb4f6be.png)

**停止镜像**

```
docker stop <CONTAINER ID >
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220221_4e495178-92ff-11ec-9cfa-fa163eb4f6be.png)

**启动镜像**

```
docker start <CONTAINER ID >
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220221_4e91c25a-92ff-11ec-9cfa-fa163eb4f6be.png)

**重启镜像**

```
docker restart <CONTAINER ID >
```

**拉取镜像**

```
docker pull <app name>
```

例如拉取最新的MongoDB镜像

```
docker pull mongo
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220221_4eb43db2-92ff-11ec-9cfa-fa163eb4f6be.png)

**查看容器内进程信息**

```
docker top <CONTAINER ID >
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220221_4f07d1e8-92ff-11ec-9cfa-fa163eb4f6be.png)

**进入容器内执行命令**

```
docker exec -it <CONTAINER ID > /bin/bash
```

**![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220221_4f4ca5ca-92ff-11ec-9cfa-fa163eb4f6be.png)**

**退出容器**

```
exit
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220221_4f6f0818-92ff-11ec-9cfa-fa163eb4f6be.png)

目前我用比较多的基础命令就是以上这些了
