最近左羊经常做一些运维相关的工作,开始的时候是使用手动写命令的方式去检测IP是否可用。检测点数量少还好数量多的情况就有些枯燥,我又改用Shell写脚本去执行,但由于Shell的批量检测是串行的等待时间较长。最后我又使用Python、Java、GoLang同时去实现，最终比较GoLang协程的方法执行时间最快且简单，分享出来留个笔记。

这里我的需求是使用ping某一个网段1至255的IP，如果ping的通就证明当前IP又在使用我们无法使用，如果ping不通就证明当前IP无人使用我们可以使用。

```
package main
import (
   "fmt"
   "github.com/go-ping/ping"
   "strconv"
   "sync"
   "time"
)
var wg sync.WaitGroup
func main() {
   start := time.Now()
   ips := "192.168.1."
   wg.Add(254)
   for i := 1; i <= 254; i++ {
      ip := ips + strconv.Itoa(i)
      go ServerPing(ip)
   }
   wg.Wait()
   run_time := time.Since(start)
   fmt.Println("Program running time:", run_time)
}
func ServerPing(ip string) {
   pinger, err := ping.NewPinger(ip)
   if err != nil {
      panic(err)
   }
   pinger.Count = 3
   pinger.SetPrivileged(true)
   pinger.Run() // blocks until finished
   stats := pinger.Statistics()
   //fmt.Println(stats)
   // PacketsRecv is the number of packets received.
   // PacketsRecv是接收到的数据包数
   // 有数据包，就可以判定ip可用的
   if stats.PacketsRecv >= 1 {
      fmt.Println(" 成功", ip)
   } else {
      fmt.Println(" 失败", ip)
   }
   wg.Done()
}
```
