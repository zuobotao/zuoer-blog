**Linux与Shell**

1. 获取系统当前时间

Linux

```
date "+%Y-%m-%d %H:%M:%S"
%Y年 %m月 %d日 %H小时 %M分钟 %S秒钟
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220714_4b61cc98-0360-11ed-846f-fa163eb4f6be.png)

Shell

```
#!/bin/bash
current_time=$(date "+%Y-%m-%d %H:%M:%S")
echo "当前日期为：" $current_time
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220714_4b834a58-0360-11ed-846f-fa163eb4f6be.png)

1. 查询创建时间为\*天前的文件

```
find "文件路径" -mtime +天数 -name '文件名'
示例
find "/home" -mtime +89 -name '*.jar'
查询home目录下文件创建时间为八十九天前,文件后缀名为.jar的全部文件
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220714_4ba88cc8-0360-11ed-846f-fa163eb4f6be.png)

1. 查询创建时间为\*天前文件的详细信息

```
find "/home" -mtime +3 -name '*.jar*' -exec ls -l {} \;
查询home目录下文件创建时间为三天前,文件后缀名为.jar的全部文件后查看它们的详细信息。
-exec 执行，表示查询到内容后执行
ls -l 查询文件详细信息
{} \; 将find查询到内容添加到此处进行作为执行的值
```

1. 查询前一年的当前月份

Linux

```
date "+%Y-%m-%d" -d 'last year'
-d 'last year' 年份为前一年
-d 'last month' 月份为前一月
-d 'last day' 日期为前一天
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220714_4bf836ba-0360-11ed-846f-fa163eb4f6be.png)

Shell

```
#!/bin/bash
last_year=$(date "+%Y-%m-%d" -d 'last year')
echo "现在日期的前一年是："$last_year
last_month=$(date "+%Y-%m-%d" -d 'last month')
echo "现在日期的前一月是："$last_month
last_day=$(date "+%Y-%m-%d" -d 'last day')
echo "现在日期的前一天是："$last_day
```
