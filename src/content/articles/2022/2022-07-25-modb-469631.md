```
#!/bin/sh
current_day=`date +'%Y-%m-%d'`


no=0
while (($no!=12))
do
no=`expr $no + '1'`


year=`date -d "${current_day} -${no} month" +%Y`
month=`date -d "${current_day} -${no} month" +%m`

done
```

**起源：一个Hive分区的坑**

后来啊！我这位朋友批了扑棱的跑了大半天的数据。

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220819_e0182c0c-1fac-11ed-82d3-fa163eb4f6be.png)

哎！完事后他去Hive控制台一瞅“数据呢？咋没上来呢？不对劲啊？”。

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220819_e01f0036-1fac-11ed-82d3-fa163eb4f6be.png)

这顿查啊，Shell脚本里外校验了好几遍，最后发现是ODS层的数据分区月份分区【1-9】月没有在前位补零，但我们看上边的脚本跑出来的时间月份的前位都是补零的。

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20220819_e0256dc2-1fac-11ed-82d3-fa163eb4f6be.png)

好嘛，定了位了嘛不，这就好办了哈。既然前位补零了我们去掉不就好了嘛，请看如下代码。

```
#!/bin/sh
current_day=`date +'%Y-%m-%d'`


no=0
while (($no!=12))
do
no=`expr $no + '1'`


year=`date -d "${current_day} -${no} month" +%Y`
month=`date -d "${current_day} -${no} month" +%_m`
echo $year
echo $month
done
```

\*提肛，提肛，Linux | Shell中的字符串替换

```
#!/bin/sh
str='a&b&c&'
# ${变量/查找/替换值}  替换第一个,特殊字符需转义
echo ${str/\&/=}
# ${变量//查找/替换值}  替换所有
echo ${str//\&/=}
```

根据综上所示的内容，我的这位朋友也去修改了他的脚本，让咱们看下吧。

```
#!/bin/sh
current_day=`date +'%Y-%m-%d'`
no=0
while (($no!=12))
do
no=`expr $no + '1'`
year=`date -d "${current_day} -${no} month" +%Y`
month=`date -d "${current_day} -${no} month" +%_m`
# ${变量/查找}  没有替换内容为空
echo "year = '$year' month = '${month/ }' "
done
```
