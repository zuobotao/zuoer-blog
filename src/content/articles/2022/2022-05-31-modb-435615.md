aggregate查询写法

```
示例
伪代码
db.集合.explain().聚合()
db.集合.聚合({},{explain:true})
示例代码
db.hero.aggregate([{$match:{"age":40}},{$group:{_id:"$gender",count:{$sum:1}}}],{explain:true})
db.hero.explain().aggregate([{$match:{"age":40}},{$group:{_id:"$gender",count:{$sum:1}}}])
查询hero集合age为40的男女分别总数
```

**索引**

**单字段索引写法**

```
示例
伪代码
db.集合.createIndex({'字段'：1})
示例代码
db.hero.createIndex({"name":1})
```

```
测试代码

**多字段索引写法**

```
示例
伪代码
db.集合.createIndex({'字段1'：1，'字段2'：1})
示例代码
db.hero.createIndex({"gender":1,"age":1})
```

测试

```
示例代码
db.hero.find({"gender":"女","age":50})
查询hero集合中gender为女，age为50的全部数据
