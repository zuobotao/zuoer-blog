为什么要配置静态IP

在实际应用中，默认我们使用的是DHCP（动态主机分配协议）来分配地址的，那么ip地址有可能是会变动的。而我们用CentOS来搭建ssh连接时，是希望IP固定不变的， 那么这个时候就需要我们配置静态IP。

首先查看系统版本

```
cat etc/redhat-release
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_3d8b6ef0-317c-11ec-989c-fa163eb4f6be.png)

第二步进入配置文件目录

```
cd etc/sysconfig/network-scripts/
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_3db9c75a-317c-11ec-989c-fa163eb4f6be.png)

小知识ifcfg-<iface> 为CentOS 7的网卡配置文件,其中iface为网卡接口名称，在我这里名为ifcfg-ens32，接下来我们将要编辑这个文件。

第三步编辑ifcfg-<iface>

```
vi ifcfg-ens32
```

初始的文件内容是这样的

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_3dea3db8-317c-11ec-989c-fa163eb4f6be.png)

主要参数说明

```
TYPE 设备类型
BOOTPROTO 启动协议{none|dhcp|static}
IPV6INIT IPV6是否有效（yes/no）
ONBOOT 开机是否启动该网卡，对虚拟接口无效{yes|no}
该文件中没有的参数，等下我们需要写入其中。
IPADDR Ip地址
GATEWAY 默认网关
DNS{1，2} DNS服务器，多个服务器使用数字标记，如DNS1,DNS2
```

第四步进行修改

```
#BOOTPROTO=dhcp 将dhcp改为static
BOOTPROTO=static
#ONBOOT=no 将no改为yes
ONBOOT=yes
该文件中没有如下参数，现在我们需要在文件最后追加
IPADDR=你想设置的Ip地址，一定要询问相关人员（运维同学）这个网段是否有在使用不然会出问题，
左羊曾因为这个问题加班了好几个小时，最后还是得益于我们的运维同学才解决的。左羊在这里匿名感谢下我的运维同学。
GATEWAY=默认网关，如果是vm虚拟可以在window使用ipconfig查看，如果是真机请自行询问运维同学或者百度。
DNS1=114.114.114.114
```

修改后的文件内容

```
TYPE=Ethernet
PROXY_METHOD=none
BROWSER_ONLY=no
BOOTPROTO=static
DEFROUTE=yes
IPV4_FAILURE_FATAL=no
IPV6INIT=no
IPV6_AUTOCONF=yes
IPV6_DEFROUTE=yes
IPV6_FAILURE_FATAL=no
IPV6_ADDR_GEN_MODE=stable-privacy
NAME=ens32
UUID=96692d7d-8800-40f3-ac47-b35cabafc3aa
DEVICE=ens32
ONBOOT=yes
IPADDR=192.0.2.15
GATEWAY=192.0.2.8
DNS1=114.114.114.114
```

最后 保存退出，重启网卡或者重启系统都行

```
CentOS 7重启网卡
systemctl restart network
重启系统
reboot
```

检查是否成功

首先

```
ifconfig
```
