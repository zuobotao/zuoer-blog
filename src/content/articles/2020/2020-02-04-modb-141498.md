DDL(Data Definition Languages)语句：数据定义语言，定义了不同的数据段、数据库、表、列、索引等数据库对象。就是对数据库内部的对象进行创建、删除、修改等操作的语言。常用的语句关键字主要包括create、drop、alter。

创建数据库

```
create datatbase db_name;
```

注：db\_name 为你想的定义数据库名

进入指定数据库

```
use db_name;
```

删除数据库

```
drop database [if exists] db_name;
```

注：if exists表示在删除数据库时判断该数据库为空才可删除

创建数据表

```
create table [if not exists/tamporary] tab_name(
列名 类型，
列名 类型，
列名 类型 ...
);
```

注：

tab\_name 为你想的定义数据表名；

if not exists表示创建表前加上一个判断，只有该表目前尚不存在时才执行create table操作；

temporaty该关键字表示用create命令创建的表为临时表；

列定义

```
col_name type [NOT NULL|NULL] [DEFAULT default_value] [AUTO_INCREMENT]
 [UNIQUE [KEY]|[PRIMARY] [KEY]] [COMMENT 'string'] [reference_definiion]
列名 数据类型 [是否为空][列的默认值]
[是否唯一|是否设为主键][对列的描述][指定参照的表和列]
```

删除表

```
drop table tab_name;
```

查看表设计信息

```
desc tab_name;
```

查看创建表SQL

```
show create table tab_name \G
```

修改表类型

```
alter table tab_name modify col_name type;
示例：alter table zuoyang modify age char(2);
```

添加表字段

```
alter table tab_name add column col_name type;
示例：alter table zuoyang add column gender char(2);
```

删除表字段

```
alter table tab_name drop column col_name;
示例：alter table zuoyang drop column gender;
```

字段改名

```
alter table tab_name chang old_col_name new_col_name type;
示例：alter table zuoyang chang age age1 char(2);
```

chang和modify都可以修改表定义，不同的是chang后面需要写两次列名，不方便；但chang的优点是可以修改列名，modify则不能；
