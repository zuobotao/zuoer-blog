首先我们看下jstack的用法

```
[root@root ~]# jstack
Usage:
    jstack [-l] <pid>
        (to connect to running process)
    jstack -F [-m] [-l] <pid>
        (to connect to a hung process)
    jstack [-m] [-l] <executable> <core>
        (to connect to a core file)
    jstack [-m] [-l] [server_id@]<remote server IP or hostname>
        (to connect to a remote debug server)


Options:
    -F  to force a thread dump. Use when jstack <pid> does not respond (process is hung)
    -m  to print both java and native frames (mixed mode)
    -l  long listing. Prints additional information about locks
    -h or -help to print this help messag
```

连接到正在运行的进程

```
jstack [-l] <pid>
        (to connect to running process)
```

连接到挂起的进程，也就是阻塞线程

```
jstack -F [-m] [-l] <pid>
        (to connect to a hung process）
```

连接到核心文件，也就是dump文件

```
jstack [-m] [-l] <executable> <core>
        (to connect to a core file)
```

连接到远程调试服务器

```
jstack [-m] [-l] [server_id@]<remote server IP or hostname>
        (to connect to a remote debug server）
```

## 使用jstack检测高占用cpu的线程

首先找到高占用CPU的进程

```
top
```

然后找到高占用CPU的线程

```
top -H -p 31194
```

线程PID转线程ID

```
printf "%x\n" 31445
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_166033b0-317c-11ec-989c-fa163eb4f6be.png)

```
jstack 31194|grep 7ad5
```
