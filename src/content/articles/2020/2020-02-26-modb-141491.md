今天左羊就以武则天（WuZeTian）与太平公主和她们男朋友们之间的关系为例讲解下ETL导入json格式数据！顺便带领大家认识不一样的武才人，武后，女帝！

首先我们创建一个名为WuZeTian的数据库

````
```
create database remote:localhost/WuZeTian root root
```
````

连接数据库

````
```
connect remote:localhost/WuZeTian root root
```
````

类/关系梳理（首先以武则天的人际关系为例）

````
```
V 顶点
person （人）


E 边缘：（lover）恋人
```
````

接下来我们创建json数据文件和json-ETL文件

wuzetian-data.json

````
```
[
{
  "id": 1,
  "name": "武则天",
  "lover":[2]
},
{
  "id": 2,
  "name": "唐太宗",
  "lover":[1]
}
]
```
````

wuzetian-ETL.json

````
```
{
  "config": {
    "log": "debug"
  },
  "source" : {
    "file": { "path": "C:/orientdb-data/wuzetian-data.json" }
  },
  "extractor" : {
    "json": {}
  },
  "transformers" : [
    { "merge": { "joinFieldName": "id", "lookup": "person.id" } },
    { "vertex": { "class": "person"} }
    ,
    { "edge": {
      "class": "lover",
      "joinFieldName": "lover",
      "lookup": "person.id",
      "direction": "in"
    } }
  ],
  "loader" : {
    "orientdb": {
      "dbURL": "remote:localhost/wuzetian",
      "dbUser": "admin",
      "dbPassword": "admin",
      "serverUser": "root",
      "serverPassword": "root",
      "dbAutoDropIfExists": true,
      "dbAutoCreate": true,
      "standardElementConstraints": false,
      "tx": false,
      "wal": false,
      "batchCommit": 1000,
      "dbType": "graph",
      "classes": [{"name": "person", "extends":"V"}, {"name": "lover", "extends":"E"}],
      "indexes": [{"class":"person", "fields":["id:integer"], "type":"UNIQUE_HASH_INDEX" }]
    }
  }
}
```
````

执行ETL程序

````
```
oetl.bat wuzetian-ETL.json
```
````

merge

当ETL模块调用Merge Transformer时，它将输入从一个ODocument实例输入到另一个，并通过查找加载。查找可以是针对索引或SELECT查询的查找。

组件说明。

- 组件名称：**合并**
- 支持的输入类型：[ **ODocument**，**OrientVertex** ]
- 输出：**ODocument**

**句法**

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 参数 | 描述 | 类型 | 强制性的 | 默认值 |
| "joinFieldName" | 定义包含连接值的字段。 | String | 是 |  |
| "lookup" | 定义要在其上执行SELECT查找或查询的索引。 | String | 是 |  |
| "unresolvedLinkAction" | 定义在尚未解决联接的情况下执行的操作。 | String |  | NOTHING |

对于该"unresolvedLinkAction"参数，支持的操作是：

|  |  |
| --- | --- |
| 行动 | 描述 |
| NOTHING | 告诉变压器什么也不做。 |
| WARNING | 告诉变压器增加警告。 |
| ERROR | 告诉变压器增加误差。 |
| HALT | 告诉变压器中断该过程。 |
| SKIP | 告诉转换器跳过当前行。 |

**例**

将当前记录与index上的查找返回的记录合并V.URI，并将其值包含在URI输入文档的字段中：

````
```
{ "merge": { "joinFieldName": "id", "lookup": "person.id" } }
```
````
