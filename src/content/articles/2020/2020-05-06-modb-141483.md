传统的jar包部署方式

```
java -jar ***.jar -xx:jvm参数


ps -ef|grep ***.jar
或
netstat -ntlp


kill -9 pid
```

这时你可以试试下面这款plus版的部署shell,轻松便捷哦

---

首先编写与jar包相对应的脚本,参考如下:

```
#!/bin/bash
#description: 启动重启server服务
#端口号，根据此端口号确定PID
PORT=你服务的端口号
#启动命令所在目录
#参考下面这条修改成你服务的绝对路径
HOME='绝对路径'


#将所有的***,都替换成你jar包的文件名
#查询出监听了grep ***.jar端口TCP协议的程序
pid=$(ps -ef | grep ***.jar | grep -v grep | awk '{print $2}')


start(){
   echo "start running cloud-core ............... "
   if [ -n "$pid" ]; then
      echo "server already start,pid:$pid"
      echo "pid:$pid 绝对路径 port:$PORT 服务已经在运行了,请停止后再 执行 sh run.sh start "
      return 0
   fi
   #进入命令所在目录
   cd $HOME
   # 启动服务控制台日志输出到nohup.out文件中
   nohup java -jar ***.jar >nohup.out 2>&1 &
   echo "running success *** port:$PORT"
   echo "*** port:$PORT 服务启动成功 ..... "
}


stop(){
   echo "stopping running cloud-core ............... "
   if [ -z "$pid" ]; then
      echo "not find program on port:$PORT"
      echo "*** port:$PORT 服务已经被关闭了请执行 sh run.sh start "
      return 0
   fi
   #结束程序，使用讯号2，如果不行可以尝试讯号9强制结束
   kill -9 $pid
   rm -rf $pid
   echo "kill program use signal 2,pid:$pid"
}


status(){
   if [ -z "$pid" ]; then
      echo "not find program on port:$PORT"
   else
      echo "program is running,pid:$pid"
   fi
}


case $1 in
   start)
      start
   ;;
   stop)
      stop
   ;;
   restart)
      stop
      pid=$(ps -ef | grep ***.jar | grep -v grep | awk '{print $2}')
      sleep 2
      start
    ;;
   status)
      status
   ;;
   *)
      echo $"Usage: $0 {start|stop|status|restart}"
      exi
```

#为sh文件赋权

```
chmod +x ***.sh
```

#移除文件中的\r sed -i 's/\r$//' filename

```
sed -i 's/\r$//' ***.sh
```

#启动shell

```
sh ***.sh start
```

#停止shell

```
sh ***.sh stop
```

#重启shell

```
sh ***.sh restart
```

#检测状态

```
sh ***.sh status
```
