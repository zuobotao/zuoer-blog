**Markdown**

Markdown是一种可以使用普通文本编辑器编写的标记语言，通过简单的标记语法，它可以使普通文本内容具有一定的格式。

# Markdown 标题

Markdown有两种标题语法

1. = 和 -

```
一级标题 左羊公社欢迎您！
=
二级标题 欢迎关注左羊公社
-
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_0c44913c-317c-11ec-989c-fa163eb4f6be.png)

1. **#**

#可表示 1-6 级标题，一级标题对应一个 **#** ，二级标题对应两个 **#** ，以此类推。

```
# 左羊公社
## 左羊公社
### 左羊公社
#### 左羊公社
##### 左羊公社
###### 左羊公社
```

# Markdown 段落

Markdown 段落没有特殊的格式，直接编写文字就好，**段落的换行是使用两个以上空格加上回车**。

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_0cac916a-317c-11ec-989c-fa163eb4f6be.png)

## Markdown 字体

```
*斜体文本*
_斜体文本_
**粗体文本**
__粗体文本__
***粗斜体文本***
___粗斜体文本___
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_0ce976f2-317c-11ec-989c-fa163eb4f6be.png)

# Markdown 列表

Markdown 支持有序列表和无序列表。

```
### 无序列表
- 左羊公社
- 左羊公社
* 左羊公社
* 左羊公社
- 左羊公社
- 左羊公社
### 有序列表
1. 左羊公社
2. 左羊公社
### 多级嵌套列表
1. 左羊公社
    - 左羊公社
    - 左羊公社
2. 左羊公社
    * 左羊公社
    - 左羊公社
3. 左羊公社
```
