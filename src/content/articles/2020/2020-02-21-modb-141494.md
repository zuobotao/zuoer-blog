左羊以王者荣耀（GloryOfKings）中简单的人物关系为例，描述如何使用orientDB图数据库创建关系图谱。

首先大家因该都了解OrientDB基本操作，不了解的话可以去看左羊的前两篇文章《OrientDB之安装AND基本操作》和《orientdb系列之常用语句》，让我们踏入王者关系的海洋吧！

首先我们创建一个名为（GloryOfKings)的数据库

```
create database remote:localhost/GloryOfKings root root
```

连接数据库

```
connetc remote:localhost/GloryOfKings root root
```

# 类/关系梳理

OrientDB数据库不仅是一个文档数据库，而且是一个图形数据库。使用诸如Vertex和Edge的新概念以图形的形式存储数据。它在顶点上应用多态性。概念Edge在某些属性的帮助下像顶点之间的关系。边和顶点是图形数据库的主要组件。它在边上应用多态性。顶点的基类是V。边缘的基类是E。

```
V 顶点（实体）
person（英雄）：周瑜，大乔，小乔，刘备，张飞，曹操
Occupation（职业）：法师，战士，肉辅，法辅
camp（阵营）：魏国，蜀国，吴国


E 边缘（关系）：
spouse（夫妻），Sisters（姐妹），Brother（兄弟），
，hostile（敌对），SecretLove（暗恋），ascription（归属），job(工作)
```

# 创建实体类（大致相当于MySQL的建表）

```
create class Person extends V
create class Occupation extends V
create class camp extends V
create class spouse extends E
create class Sisters extends E
create class Brother extends E
create class hostile extends E
create class SecretLove extends E
create class ascription extends E
create class job extends E
```

# 创建**Edge**

归属关系实体

```
ascription（归属）
create edge ascription from(select from Person where name="周瑜") to(select from camp where name="吴国")
create edge ascription from(select from Person where name="大乔") to(select from camp where name="吴国")
create edge ascription from(select from Person where name="小乔") to(select from camp where name="吴国")
create edge ascription from(select from Person where name="刘备") to(select from camp where name="蜀国")
create edge ascription from(select from Person where name="张飞") to(select from camp where name="蜀国")
create edge ascription from(select from Person where name="曹操") to(select from camp where name="魏国")
```
