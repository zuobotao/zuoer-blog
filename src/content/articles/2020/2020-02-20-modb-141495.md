# 库操作

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_2eb86ca2-317c-11ec-989c-fa163eb4f6be.png)

连接数据库

```
connect remote:localhost/zuoyang root root
```

查看所有数据库

```
list databases
```

创建数据库

```
create database remote:localhost/zuoyang root root
```

退出数据库

```
disconnect
```

修改数据库

```
ALTER DATABASE custom strictSQL = false
```

冻结数据库

```
freeze database
```

释放数据库

```
release database
```

导出数据库

```
export database F://zuoyang.export
```

导入数据库

```
import database F://zuoyang.export.gz
```

删除数据库

```
drop database
```

# 类操作

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_2f1efb66-317c-11ec-989c-fa163eb4f6be.png)

创建类

```
create class zuobotao
```

修改类

```
alter class zuobotao name yangjiaoai
```

删除类

```
drop class yangjiaoai
```

查看所有类

```
list classes
```

# 属性操作

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_2f5dd336-317c-11ec-989c-fa163eb4f6be.png)

创建属性

```
create property zuobotao.name string
```

改变属性

```
alter property zuobotao.name name sex
```

# CRUD操作

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_2f86e0aa-317c-11ec-989c-fa163eb4f6be.png)

插入操作

```
insert into zuobotao(sex) values("nan")
```

批量插入

```
insert into zuobotao(sex) values("nan")，("nv")，("?"),("御马监")
```

查看操作

```
select * from zuobotao
```

条件查询

```
select * from zuobotao where sex="御马监"

select sex from zuobotao
```

更新操作

```
update zuobotao set sex="nv" where sex="nan"
```

删除操作

```
delete from zuobotao where sex="nv"
```

# 顶点操作

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_2fbe8dd4-317c-11ec-989c-fa163eb4f6be.png)

创建顶点

```
create class Person extends V

create vertex Person set name="linghucong",sex="nan",age="25"
```

移动顶点

```
move vertex #33:0 to class:zuobotao
```

删除顶点

```
delete vertex #33:0
```

# 边操作

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_2fe8f95c-317c-11ec-989c-fa163eb4f6be.png)

创建边

```
create class Lover extends E

create vertex Person set name="linghucong",sex="nan",age="25"
```

更新边

```
update edge lover set to=(select from person where name="zhangwuji") where name="linghucong"
```

删除边

```
delete edge from #34:0 to #35:0
```
