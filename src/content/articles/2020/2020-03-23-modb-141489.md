首先我们创建一个名为beauty的数据库

```
create database remote:localhost/beautyroot root
```

连接数据库

```
connect remote:localhost/beautyroot root
```

接下来我们创建ETL的json文件

Power.json

```
{
  "config": {
    "log": "debug"
  },
  "extractor" : {
    "jdbc": { "driver": "com.mysql.jdbc.Driver",
              "url": "jdbc:mysql://localhost/beauty",
              "userName": "root",
              "userPassword": "你的mysql密码",
              "query": "select * from power" }
  },
  "transformers" : [
   { "vertex": { "class": "power"} }
  ],
  "loader" : {
    "orientdb": {
      "dbURL": "remost:localhost/beauty",
      "serverUser": "root",
      "serverPassword": "root"
    }
  }
}
```

执行

```
oetl.bat power.json
```
