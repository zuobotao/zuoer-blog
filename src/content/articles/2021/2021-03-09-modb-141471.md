### **一 数据库的创建与删除**

#### **创建数据库**

语法

````
```
use DATABASE_NAME
```
````

示例

````
```
> use ming_dynasty
switched to db ming_dynasty
> db
ming_dynasty
```
````

#### **删除数据库**

语法

````
```
db.dropDatabase()
```
````

示例

1. 进入数据库

````
```
> use ming_dynasty
switched to db ming_dynasty
```
````

1. 执行删除命令

````
```
> db.dropDatabase()
{ "ok" : 1 }
```
````

### **二 集合的创建与删除**

#### **创建集合**

语法

````
```
db.createCollection(name, options)
```
````

示例

````
```
> use ming_dynasty
switched to db ming_dynasty
> db.createCollection("hero")
{ "ok" : 1 }
```
````

**删除集合**

语法

````
```
db.collection.drop()
```
````

示例

````
```
> db.hero.drop()
true
```
````

### **三 插入操作**

#### **单条插入**

Mysql写法

````
```
INSERT into hero value(1,'朱元璋','男','皇帝','洪武大帝')
```
````

mongodb语法

````
```
db.COLLECTION_NAME.insert(document)
```
````

mongodb示例

````
```
> db.hero.insert({"name":"朱元璋","gender":"男","position":"皇帝","note":"洪武大帝"})
WriteResult({ "nInserted" : 1 })
> db.hero.find()

#### **查询条件比对**

1. 等于

Mysql写法

````
```
SELECT * from hero WHERE name='朱元璋'
```
````

mongodb示例

````
```
> db.hero.find({"name" : "朱元璋"})
```
````

1. 不等于

Mysql写法

````
```
SELECT * from hero WHERE name != '朱元璋'
```
````

mongodb示例

````
```
> db.hero.find({"name" :{$ne: "朱元璋"}})
```
````

1. 大于(懒得想逻辑了就用String类型写了，各位记得用数值类型试哈)

Mysql写法

````
```
SELECT * from hero WHERE name > '朱元璋'
```
````

mongodb示例

````
```
> db.hero.find({"name" :{$gt: "朱元璋"}})
```
````

1. 大于等于(懒得想逻辑了就用String类型写了，各位记得用数值类型试哈)

Mysql写法

````
```
SELECT * from hero WHERE name >= '朱元璋'
```
````

mongodb示例

````
```
> db.hero.find({"name" :{$gte: "朱元璋"}})
```
````

1. 小于(懒得想逻辑了就用String类型写了，各位记得用数值类型试哈)

Mysql写法

````
```
SELECT * from hero WHERE name < '朱元璋'
```
````

mongodb示例

````
```
> db.hero.find({"name" :{$lt: "朱元璋"}})

````

1. 小于等于(懒得想逻辑了就用String类型写了，各位记得用数值类型试哈)
