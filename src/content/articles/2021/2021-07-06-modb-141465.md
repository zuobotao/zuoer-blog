## **Ffmpeg命令格式简介** ``` ffmpeg {1} {2} -i {3} {4} {5} ``` 1.全局参数 2.输入文件参数 3.输入文件 4.输出文件参数 5.输出文件 **一、Rtsp直播推送** ```` ``` ffmpeg -i rtsp://***** -c:v libx264 -c:a copy -f flv rtmp://****** ``` ```` #-c:v：指定视频编码器 #-c:a：指定音频编码器 # libx264：最流行的开源 H.264 编码器 #-f flv 强迫采用格式flv **二、本地MP4视频推送** ```` ``` ffmpeg -i *.mp4 -c:v libx264 -c:a copy -f flv rtmp://**** ``` ```` **三、本地MP4视频循环推送** ```` ``` ffmpeg -stream_loop -1 -i *.mp4 -c:v libx264 -c:a copy -f flv rtmp://**** ``` ```` #-stream\_loop 指定循环读取视频源的次数，-1为无限循环 **四、本地MP4视频加时间水印推送** ```` ``` ffmpeg -i *.mp4 -vf "settb=AVTB,setpts='trunc(PTS/1K)*1K+st(1,trunc(RTCTIME/1K))-1K*trunc(ld(1)/1K)',drawtext=fontsize=15:fontcolor=white:text='%{localtime}.%{eif\:1M*t-1K*trunc(t*1K)\:d}'" -c:v libx264 -c:a copy -f flv rtmp://**** ``` ```` #fontsize 字体大小，单位像素 #fontcolor 字体颜色 **五、 Rtsp监控流截图** ```` ``` ffmpeg -i rtsp://*** -y -f mjpeg -t 0.001 test.jpg ``` ```` #-y：不经过确认，输出时直接覆盖同名文件。 #-f mjpeg 强迫采用格式jpg #-t duration 设置记录时间 hh:mm:ss[.xxx]格式的记录时间也支持 **六、Rtsp拉流优化** ```` ``` ffmpeg -re -rtsp_transport tcp -i rtsp://*** -c:a copy -c:v libx264 -f flv rtmp://*** ``` ```` #-re :就是根据文件真实的帧率来读取文件，生成实时刷新的直播流 #-rtsp\_transport tcp:强制使用TCP方式处理rtsp流，防止UDP方式丢包
