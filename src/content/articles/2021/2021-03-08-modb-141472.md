## **各系统平台如何安装MonGoDB？**

###

### windows 10安装

安装包下载地址

```
https://www.mongodb.com/try/download/community
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_01382f88-317c-11ec-989c-fa163eb4f6be.png)

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_017fc352-317c-11ec-989c-fa163eb4f6be.png)

安装步骤

```
Next-》同意-》Complete选择安装路径及数据存放路径-》Next-》Next->Install
```

配置环境变量

左羊是默认安装的，默认安装路径为

```
C:\Program Files\MongoDB\Server\4.4\bin
```

将其配入环境变量的path中即可

验证方式

```
win+r
cmd
mongo
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_01b1caaa-317c-11ec-989c-fa163eb4f6be.png)

出现上图所示即为安装成功！

### **Centos7 安装**

1. 下载

```
wget -0 https://mirrors.tuna.tsinghua.edu.cn/mongodb/yum/el7-4.2/RPMS/mongodb-org-mongos-4.2.0-1.el7.x86_64.rpm
```

1. 安装

```
rpm -ivh mongodb-org-mongos-4.2.0-1.el7.x86_64.rpm
```

1. 修改配置文件

```
vim etc/mongod.conf
将127.0.0.1改为0.0.0.0开启远程访问
```

1. 启动mongod服务

```
systemctl start mongod
```

1. 验证

mongo

出现下图即为安装成功

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_0226382c-317c-11ec-989c-fa163eb4f6be.png)
