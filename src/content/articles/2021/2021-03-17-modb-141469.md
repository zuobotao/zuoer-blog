场景描述:2021年3月的一段时间,我的电话快被客服部门同事打爆了，大家都反馈我们的产品内图片加载异常的慢。

我首先拿到一张图片的链接到浏览器中直接下载观察速度发现确实很慢不是客户终端的问题，然后左羊又通过在一台Linux服务器使用wget命令下载图片观测网络下行速度发现仅仅几Kb每秒，这是我意识到可能是图片资源服务器出问题了，但是图片资源服务的上行带宽为10Mb/s。左羊就有点不知所措了。抓紧求助运维部门的同事，首先跟同事一起观察了阿里云的服务器监控，发现图片资源服务器高峰期的上行带宽已经达到10Mb/s了，我就懵了，我就是在浏览器上看个图片啊，怎么可能在占用这么高的带宽呢！最后还是同事点了我一下使用iftop工具看下到底是哪些ip大量占用带宽。最后左羊通过iftop工具分析后发现是同在阿里云的图片分析服务在大量通过公网IP从图片资源服务器下载图片进行业务分析。原来问题点在这里，最后我带着在阿里云网站上面查到的阿里云内网服务器资源传输最大带宽可以达到10Gb/s的结果将图片分析服务通过公网下载改为通过阿里云内网下载，修改后公网上行带宽从10Mb/s降到了500Kb/s左右，最后又看了看图片的加载速度丝滑。

iftop简介

Cent os7安装

```
yum install iftop -y
```

使用

```
iftop
```

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_fba41690-317b-11ec-989c-fa163eb4f6be.png)

```
TX：发送流量
RX：接收流量
TOTAL：总流量
Cumm：运行iftop到目前时间的总流量
peak：流量峰值
rates：分别表示过去 2s 10s 40s 的平均流量
=>:上行
<=:下行
```

进入iftop界面后（上图），按t可以切换上行下行显示。
