进程查看命令

```
ps -ef|gerp java
```

Ssh远程连接

```
ssh root@192.0.2.8 -P 2211
指令 用户名@IP地址 -P sshd端口
```

Scp文件同步命令

Linux版

```

```

```
[上传]
scp /home/a.txt root@192.0.2.8:/home/a.txt
指令 本机文件绝对路径 用户名@目标机器IP地址:目标文件绝对路径
[下载]
scp -P 8888 root@192.0.2.8:/home/a.txt /home/a.txt
指令 -P 目标机器端口 用户名@目标机器IP地址:目标文件绝对路径 本机文件绝对路径
```

```
Linux firewall防火墙操作
```

```
开启8080端口
firewall-cmd --add-port=8080/tcp
关闭8080端口
firewall-cmd --remove-port=8080/tcp
查看8080端口
firewall-cmd --query-port=8080/tcp
```

查看历史命令

```
history
```

后台启动程序指令

```
nohup java -jar zuoyang.jar &
```

文件操作

```
复制
cp /home/a.txt /opt/a.txt
移动
mv /home/a.txt /opt/a.txt
赋执行权限
chmod +x a.sh
```

```
编辑文件
```

```

```

杀死进程

```
kill -9 10800
指令     进程号
```

查看文件占用情况

```
df -h
```

设置定时任务

```
crontab -e
cron公式在线工具
https://tool.lu/crontab/
```

重启

```
reboot
```

关机

```
shutdown -h now
```

抓包

```
tcpdump tcp -i eth4S -t -s 0 -c 100 and dst port 8848 and src net 192.0.2.8/24 -w /home/a.cap
```

批量杀死进程

```
ps -ef|grep java|grep -v grep|awk  '{print "kill -9 " $2}' |sh
```
