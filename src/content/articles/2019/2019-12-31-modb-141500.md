JDK1.8在LINUX下安装步骤：

1. 在/usr/lib/目录下新建jvm文件夹，如果已有jvm文件夹，则将之前的JDK版本删除，即在jvm目录下执行命令：

```
rm –rf *
```

2. 将JDK文件jdk-8u40-linux-x64.gz拷贝到/home/目录下；

3. 在/home/目录下执行命令：

```
sudo tar zxvf ./jdk-8u40-linux-x64.gz  -C usr/lib/jvm
```

4. 修改环境变量，执行命令：

```
vi ~/.bashrc
```

5. 在文件内容的末尾添加以下内容：

```
export JAVA_HOME=/usr/lib/jvm/jdk1.8.0_40

export JRE_HOME=${JAVA_HOME}/jre

export CLASSPATH=.:${JAVA_HOME}/lib:${JRE_HOME}/lib

export PATH=${JAVA_HOME}/bin:$PATH
```

然后保存退出。

6. 输入命令使之立即生效：

```
source ~/.bashrc
```

7. 执行命令：java –version查询java版本，如下图所示：
