Shenandoah: A Low-Pause-Time Garbage Collector (Experimental)

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_5d8ac14c-317c-11ec-989c-fa163eb4f6be.png)

```
添加一个名为Shenandoah的新垃圾收集(GC)算法，该算法通过与正在运行的Java线程并发执行
回收工作来减少GC暂停时间。Shenandoah的暂停时间与堆大小无关，这意味着无论堆大小是
200mb还是200gb，您都将拥有相同的一致暂停时间。
```

Microbenchmark Suite

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_5dca1798-317c-11ec-989c-fa163eb4f6be.png)

```
在JDK源代码中添加一组基本的微基准测试，使开发人员可以轻松地运行现有的微基准测试并创建新的微基准测试。
```

Switch Expressions (Preview)

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_5e019e66-317c-11ec-989c-fa163eb4f6be.png)

```
扩展switch语句，使其既可以用作语句，也可以用作表达式，并且两种形式都可以使用“传统
的”或“简化的”范围和控制流行为。这些更改将简化日常编码，并为在switch中使用模式匹配(
JEP 305)做好准备。这将是一个预览语言特性。
```

JVM Constants API

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_5e3c2cde-317c-11ec-989c-fa163eb4f6be.png)

```
引入一个API来建模关键类文件和运行时构件的标称描述，特别是可从常量池加载的常量。
```

One AArch64 Port, Not Two

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_5e6d58e0-317c-11ec-989c-fa163eb4f6be.png)

```
删除与arm64端口相关的所有源，同时保留32位ARM端口和64位aarch64端口。
```

Default CDS Archives

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_5ea5ffce-317c-11ec-989c-fa163eb4f6be.png)

```
确保JDK构建过程能够在64位平台上使用默认的类列表生成类数据共享(CDS)存档。
```

Abortable Mixed Collections for G1

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_5eedb9f4-317c-11ec-989c-fa163eb4f6be.png)

```
如果G1混合集合可能超过暂停目标，则使其中止。
```

Promptly Return Unused Committed Memory from G1

![](https://oss-emcsprod-public.modb.pro/wechatSpider/modb_20211020_5f1c13c6-317c-11ec-989c-fa163eb4f6be.png)

```
增强G1垃圾收集器，以便在空闲时自动将Java堆内存返回到操作系统。
```
