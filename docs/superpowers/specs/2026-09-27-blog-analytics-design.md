# 博客统计设计

用户要求增加阅读人数、访客人数、IP 等统计，并执行已有内网监控方案。

沿用 Astro 静态网页，扩展现有 Python 服务提供同源 `/api/analytics/view` 与 `/api/analytics/counts`。访客进入可见页面五秒后记录一次访问；相同匿名访客、规范化页面半小时内去重，中文/英文共用内容路径。阅读人数是访问过文章页面的匿名 IP 数，不代表读完文章；共享网络会合并人数，IP 改变可能重复计数。不使用 Cookie、浏览器指纹或第三方统计服务，尊重 DNT/GPC。

SQLite 存在发布目录之外，只保存时间、规范化路径、HMAC 匿名访客标识、脱敏 IP 网段、来源域名、设备类别。完整 IP 仅在请求处理时用于匿名化，不入库或日志。仅信任环回请求中的 Cloudflare 客户端 IP，拒绝外网直连时伪造的代理头。数据保留 90 天，公开页明确统计窗口，服务错误显示不可用而不是零。

独立内网服务 8765 展示系统资源、服务状态、游戏房间与访问趋势、热门路径、来源、脱敏 IP 网段。8765 按真实连接来源限制私网及本机访问，不读代理头，也拒绝非预期 Host/Origin。房间统计只监听 127.0.0.1:8788，白名单汇总六种状态及连接数。五秒刷新，浏览器趋势最多五分钟。部署新增 20-zuoer-monitor 启动脚本，保留现有博客/游戏/隧道脚本。

验证：去重、双语归一化、伪造代理头、隐私字段、统计窗口、探测超时与权限控制单测；博客 check/build/test；真实 HTTP 统计、内网页面、房间聚合和重复启动检查。发布前备份并使用独立 release，旧版本保留可回退。房间服务有活动游戏时延期重启以免清空房间。
